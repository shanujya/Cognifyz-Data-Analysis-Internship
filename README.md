# Cognifyz Technologies - Data Analysis Internship 🚀

This repository contains the code and report for the Data Analysis Internship task assigned by **Cognifyz Technologies**. The project involves analyzing a comprehensive restaurant dataset to uncover actionable insights regarding cuisines, geographic spread, pricing strategies, and customer ratings.

## 📌 Project Overview
The objective of this project is to apply data preprocessing, exploratory data analysis (EDA), and advanced analytical techniques to extract meaningful patterns from real-world data. 

**Note:** All three levels of the internship tasks (Level 1, 2, and 3) were completed, along with data quality checks and outlier detection.

## 🛠️ Technologies Used
* **Python** * **Pandas** (Data manipulation and cleaning)
* **Matplotlib & Seaborn** (Data visualization and geospatial plotting)
* **Jupyter Notebook** (IDE)

## 📊 Key Highlights & Analysis
* **Data Preprocessing:** Handled missing values in cuisine data and identified major currency/vote outliers.
* **Level 1 Analysis:** Identified top cuisines (North Indian, Chinese), city distributions, and online delivery trends.
* **Level 2 Analysis:** Mapped the geographic distribution of restaurants and evaluated the performance of major restaurant chains (e.g., Domino's, Cafe Coffee Day).
* **Level 3 Analysis:** Extracted sentiment from categorical reviews, analyzed vote-to-rating correlations, and mapped service availability against restaurant price ranges.

## 📁 Files in this Repository
* `Dataset .csv`: The raw dataset used for analysis.
* `Cognifyz_Data_Analysis.ipynb`: The complete Python code containing all levels of analysis.
